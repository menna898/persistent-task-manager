# Persistent Task Manager 📝

A lightweight and efficient Command-Line Interface (CLI) Task Manager built with **Python**. This project focuses on **data persistence**, ensuring that all your tasks, logs, and schedules are saved securely in a local file and never lost when the application closes.

## 🚀 Features
- **Data Persistence:** Automatically saves tasks to a local file and loads them upon startup.
- **Task Management:** Add, view, and organize your daily tasks easily.
- **Clean Code:** Structured logic built with clean Python practices.

## 🛠️ Tech Stack
- **Language:** Python 3
- **Storage:** File Handling (TXT / JSON persistence)

## 📌 Why this project?
I built this project to master memory management and file I/O operations, which are foundational concepts in software engineering and cybersecurity automation.
